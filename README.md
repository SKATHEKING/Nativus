# Nativus

Nativus is a modern music label website for showcasing releases, featured artists, merch, visual art, and future supporter tools. This repository currently contains the first skeleton version of the project, designed as a clean base that can grow over time.

## What This Project Is

This site is being built as a digital home for the Nativus label. The long-term goal is to give the project a place to:

- Host and present albums, singles, and other releases
- Showcase featured artists and collaborators
- Share music links and future audio playback experiences
- Offer a support section for people who want to contribute financially
- Sell merch and art through a dedicated shop area
- Expand into a proper admin workflow for managing content later

## Current Status

The project is currently a skeleton, which means the layout and main pages are in place, but the real data, media uploads, payments, and database integrations will be added later.

What exists now:

- A branded homepage with placeholder content
- Shared site header and footer
- Placeholder pages for music, artists, support, shop, cart, and admin
- A simple content file for reusable starter text
- A visual direction that feels warm, cinematic, and label-focused

## Planned Features

The project is intended to grow into the following areas:

### Music

- Album and single pages
- Release artwork and tracklists
- Download and streaming links
- Future audio player support

### Artists

- Featured artist profiles
- Artist bios and social links
- Discography sections
- Artist-specific release pages

### Support

- One-time support or tipping
- Monthly supporter options
- Future donation and membership flows

### Shop

- Merch listings
- Art prints and visual pieces
- Product detail pages
- Cart and checkout flow

### Admin

- Release management
- Artist management
- Product management
- Support and sales tracking later on

## Tech Direction

The starter is set up with a modern Next.js foundation and is intended to eventually use:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase for data and auth
- Stripe for payments
- Vercel Blob for media storage
- Motion for animations

## Project Structure

The current structure is organized around the main public sections of the label site:

- `src/app` for pages and layouts
- `src/components` for shared UI pieces
- `src/lib` for reusable content and future helpers
